# 1. Objetivo

Consolidar, em um único documento técnico, o que é **evidência real** (vindo
de interação com a empresa parceira) e o que é **hipótese** (ainda não
validada), separando claramente as duas categorias — conforme exigido pelo
diagnóstico acadêmico do PI III.

Este documento é a fonte para o `.context`; o conteúdo completo, formatado
para entrega acadêmica, está em `03_01_Diagnostico_e_Design_Thinking` (fora
do repositório, entregue via Google Classroom).
